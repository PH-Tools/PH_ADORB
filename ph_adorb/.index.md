# ph_adorb/ — the package

The ADORB cost calculation. See `../context/ARCHITECTURE.md` (authoritative deep docs in `../docs/architecture.md`).

## Core modules

- `variant.py` — the building variant being evaluated (central object).
- `adorb_cost.py` — the ADORB cost calculation.
- Inputs: `constructions.py`, `equipment.py`, `fuel.py`, `grid_region.py`, `national_emissions.py`, `measures.py`, `yearly_values.py`, `ep_sql_file.py`.

## Subpackages

- `from_HBJSON/` — build a `Variant` from a Honeybee-REVIVE model (`read_HBJSON_file.py`, `create_variant.py`).
- `run/` — orchestration (`calc_HBJSON_ADORB_costs.py`) + plotly output (`generate_ADORB_cost_graph.py`).
- `tables/` — tabular output builders.

## Notes
- CPython numeric library (pandas/plotly). Tests: `../tests/`. Correctness anchored to `../_reference/`.
