# planning/

Working plans for PH-ADORB. See [`.instructions.md`](.instructions.md) for the rules and folder contract.

**Read order:** [`STATUS.md`](STATUS.md) first.

## Layout

- `STATUS.md` — master index of active work.
- `features/` — plans for new capabilities.
- `archive/` — completed/superseded work, flat by slug, indexed in `archive/README.md`.
- `docs-plan.md`, `docs-rewrite-plan.md` — the documentation build-out/rewrite plans (relocated here from `docs/`).

When an item is done, fold its outcome into `context/`, then move it into `archive/<slug>/` and add a row to `archive/README.md`.
